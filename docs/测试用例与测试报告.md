## 1. 测试概述

### 1.1 测试目的

本次测试旨在验证车辆年检预约管理系统的功能正确性、接口稳定性以及核心业务流程的完整性。通过后端的 pytest 单元/集成测试、前端 Vitest + React Testing Library 页面单元测试，以及端到端跑批脚本，覆盖用户认证、检测站管理、车辆管理、预约管理、检测报告与统计导出等关键模块，确保系统达到可交付质量。

### 1.2 测试范围

| 范围类型 | 说明 |
| --- | --- |
| 测试对象 | 后端 API（FastAPI）+ 前端 React 页面 |
| 包含模块 | 认证授权、检测站管理、车辆管理、预约管理、检测报告与统计导出、前端各角色页面 |
| 测试类型 | 后端单元/接口测试、前端页面单元测试、端到端业务流程跑批 |
| 不包含 | 前端 E2E 自动化测试、性能压力测试、安全渗透测试 |

### 1.3 测试策略

- **后端 pytest 单元/集成测试**：使用 FastAPI TestClient 对各业务模块的接口进行黑盒测试，验证状态码、返回数据、权限控制与业务规则。
- **前端 Vitest 页面单元测试**：使用 jsdom + React Testing Library 对登录、注册、车主、检测站、管理员等页面进行渲染与交互测试，覆盖条件渲染、表单提交、错误分支与异步副作用。
- **端到端跑批脚本**：启动真实 FastAPI 服务，使用独立 SQLite 数据库，模拟从注册、建站到检测、导出报表的完整业务流程，确认系统在实际运行环境中的可用性。
